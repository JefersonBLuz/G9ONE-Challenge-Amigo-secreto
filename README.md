## 📝 Descrição do Projeto

Este projeto foi desenvolvido durante minha participação no [Programa ONE - Oracle Next Education - Turma 9](https://www.oracle.com/br/education/oracle-next-education), como parte de um desafio de seleção do G9ONE. O objetivo é proporcionar uma experiência prática e intuitiva para quem deseja aprimorar suas habilidades em lógica de programação, manipulação de arrays e interação com o usuário em uma interface web. A aplicação permite que o usuário adicione nomes de participantes, que são armazenados em um array, e realize de forma dinâmica e aleatória o sorteio do amigo secreto, tornando o aprendizado de JavaScript mais envolvente e acessível.

Se você também tem interesse em desenvolver suas habilidades em programação, participe do programa pelo link abaixo:

[![Participe do ONE - Oracle Next Education](https://img.shields.io/badge/Participe%20do%20ONE%20-%20Oracle%20Next%20Education-1a73e8?logo=oracle&logoColor=white)](https://www.oracle.com/br/education/oracle-next-education)

## 🚀 Funcionalidades e Demonstração

- **Inserção de nomes de participantes** com validações:
  - Não aceita nomes vazios ou apenas espaços em branco
  - Não permite nomes duplicados na lista
- **Sorteio automático e aleatório** de amigo secreto
- **Interface simples e intuitiva** com feedback visual
- **Validações em tempo real** para garantir a integridade dos dados
- **Mensagens de erro integradas** no HTML (sem popups)
- **Botão de sortear inteligente** (desabilitado para lista ≤ 1)
- **Botão de reiniciar** para limpar toda a lista
- **Tooltip informativo** no botão desabilitado
- **Tabela com scroll** para gerenciar muitos nomes
- **Edição e exclusão** de nomes com ícones
- **Formatação automática** de nomes (capitalização)
- **Lista ordenada** alfabeticamente
- **Responsividade completa** para desktop, tablet e mobile
- **Layout adaptativo** com componentes em coluna no mobile
- **Imagens proporcionais** mantendo aspect ratio
- **Fontes otimizadas** para diferentes tamanhos de tela<br>
